Research often involves having to keep track of a wide array of different files of code, many of which will change constantly as you experiment with different options and ways of doing things.
It is very easy to end up with messy folders full of old versions of code, or to forget what you did - or not be able to find old versions when you need them for a paper.

This workshop covers automated version control, a process for tracking changes to files and folders within a "repository".
It will show you how to use the Git version control system to manage your code, tracking changes to files, inspecting and merging multiple different changes, and how to collaborate with other Git users using the GitHub online respository store.

### Premise

You have been handed some data analysis code written by a previous PhD student, that is intended to load and analyse files containing climate data.
It has been uploaded to **GitHub** online - you want to download it, and start making changes.
